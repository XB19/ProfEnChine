# Projet LeProf AI

## Contexte
Ce projet est développé avec Django.

Objectif :
Créer une plateforme d'IA robuste, maintenable et professionnelle.

## Règles importantes

- Ne jamais supprimer une fonctionnalité existante sans autorisation.
- Toujours expliquer les modifications importantes.
- Corriger uniquement les problèmes identifiés.
- Respecter les bonnes pratiques Django.
- Éviter les duplications de code.
- Préserver l'architecture actuelle.
- Toujours vérifier les imports.
- Toujours vérifier les URLs.
- Toujours vérifier les migrations.
- Toujours vérifier les modèles.
- Toujours vérifier les serializers.
- Toujours vérifier les permissions.
- Toujours vérifier les vues.
- Toujours vérifier les services IA.
- Toujours vérifier les API.
- Toujours lancer les tests adaptés après une modification.
- Éviter d'ajouter des dépendances inutiles.

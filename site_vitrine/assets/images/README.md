# Images du site

- `hero.jpg` — photo de fond de la section d'accueil (skyline, redimensionnée et compressée pour le web)
- `cta.jpg` — photo de fond de la bannière finale (même skyline, variante)
- `student.jpg` — photo de l'étudiante (fond blanc en haut) : pas encore intégrée dans une section, en réserve pour un futur emplacement dédié (nécessite un traitement CSS spécifique pour un rendu propre vu son fond)

Les deux photos de fond s'affichent derrière un voile rouge/noir semi-transparent (déjà en place) pour que le texte blanc reste lisible.

Pour remplacer une image : déposez un nouveau fichier avec le même nom. Pensez à le compresser (idéalement < 400 Ko, largeur ~1800-2000px) pour ne pas ralentir le chargement du site.

# Images du site

Déposez vos fichiers ici avec exactement ces noms — ils s'affichent automatiquement, aucune modification de code nécessaire :

- `hero.jpg` — photo de fond de la section d'accueil (grande image, format paysage, ex. 1600×1000px)
- `cta.jpg` — photo de fond de la bannière finale "Prêt(e) à démarrer votre dossier ?" (format paysage large)

Les deux s'affichent derrière un voile rouge/noir semi-transparent (déjà en place) pour que le texte blanc reste lisible — pas besoin de les assombrir vous-même.

Tant qu'un fichier n'est pas présent, la section garde son fond de couleur actuel (aucun visuel cassé).

D'autres emplacements (cartes programmes, section bourse...) pourront être ajoutés sur demande une fois ces deux premiers en place.
